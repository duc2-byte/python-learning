# Python Learning Journey 🐍

This repository documents my Python learning journey through the freeCodeCamp Scientific Computing with Python curriculum.

## Learning Goals

* Learn Python fundamentals
* Practice problem-solving and logical thinking
* Develop Git and GitHub skills
* Build small projects and applications
* Learn to manage tasks and report progress
* Build a portfolio of coding projects

## Course

Scientific Computing with Python (freeCodeCamp)

Course Link:
https://www.freecodecamp.org/learn/scientific-computing-with-python/

## Learning Workflow

Every week follows the same process:

1. Create learning tasks
2. Study lessons
3. Complete exercises
4. Commit progress to GitHub
5. Submit weekly report
6. Demo completed work
7. Receive feedback and improve

## Git Commit Rules

Use meaningful commit messages.

Examples:

```text
Complete exercise 1
Add calculator project
Fix odd/even logic
Update week 3 report
```

Avoid:

```text
update
fix
123
test
```
